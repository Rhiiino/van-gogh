# Van Gogh — Logic board (KiCad)

Right-barrel barrel control unit (BCU) PCB. Open `barrel-logicBoard-vanGogh.kicad_pro` in KiCad.


| Item       | Value                         |
| ---------- | ----------------------------- |
| Board size | 56 × 92.6 mm                  |
| Layers     | 2                             |
| Thickness  | 1.6 mm                        |
| Copper     | 1 oz                          |
| Finish     | Black soldermask (as ordered) |


## Fabrication

**[gerber.zip](gerber.zip)** is the Gerber and drill export for PCB fab. It matches the board ordered from JLCPCB as **Y14-2705430A**. Upload the zip as-is; no KiCad required to order bare boards.
